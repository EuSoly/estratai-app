# EstratAI Environment Variables Documentation

## Overview
All sensitive and configurable values are managed through environment variables. This prevents hardcoding secrets and allows different configurations per environment (dev, staging, production).

## Variables Reference

### Supabase Configuration
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_SUPABASE_URL` | Supabase project URL | ✅ Yes | None |
| `VITE_SUPABASE_ANON_KEY` | Supabase anonymous key | ✅ Yes | None |

### Application Configuration
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_APP_NAME` | Application display name | ❌ No | EstratAI |
| `VITE_API_URL` | Backend API base URL | ❌ No | http://localhost:3000 |
| `VITE_APP_URL` | Frontend application URL (for redirects) | ❌ No | http://localhost:5173 |

### N8N Integration
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_N8N_WEBHOOK_URL` | N8N webhook endpoint for AI analysis | ❌ No | None |

### File Upload Constraints
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_MAX_FILE_SIZE_MB` | Maximum file upload size in MB | ❌ No | 20 |
| `VITE_ALLOWED_FILE_TYPES` | Comma-separated list of allowed file extensions | ❌ No | pdf,docx,pptx,xlsx,csv,txt |

### UI/UX Configuration
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_SEARCH_DEBOUNCE_MS` | Debounce delay for file search in milliseconds | ❌ No | 300 |
| `VITE_SESSION_TIMEOUT_MINUTES` | Session timeout duration | ❌ No | 30 |
| `VITE_TOKEN_REFRESH_MINUTES` | Token refresh interval | ❌ No | 25 |

### Feature Flags
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_FEATURE_EXPORT_PDF` | Enable PDF export functionality | ❌ No | true |
| `VITE_FEATURE_WEBHOOK` | Enable N8N webhook integration | ❌ No | true |
| `VITE_FEATURE_PLAN_GATING` | Enable subscription plan restrictions | ❌ No | true |

### Debug & Logging
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_DEBUG` | Enable debug mode with verbose logging | ❌ No | false |
| `VITE_LOG_LEVEL` | Log level: 'error', 'warn', 'info', 'debug' | ❌ No | info |

### Plan Names
| Variable | Purpose | Required | Default |
|----------|---------|----------|---------|
| `VITE_PLAN_STARTER` | Starter plan name | ❌ No | Starter |
| `VITE_PLAN_BUSINESS` | Business plan name | ❌ No | Business |
| `VITE_PLAN_ENTERPRISE` | Enterprise plan name | ❌ No | Enterprise |

## How to Use

### Development
1. Copy `.env.example` to `.env`
2. Fill in the required values (Supabase URL and key)
3. Optional: Configure N8N webhook URL and other settings
4. Run `npm run dev`

### Production
1. Set environment variables via your deployment platform:
   - GitHub Actions secrets
   - Docker environment files
   - Cloud provider (Vercel, Netlify, etc.)
2. Ensure all required variables are set before deploying

### Configuration Centralization
All environment variables are imported and validated in `src/config/env.js`.
This file:
- Provides TypeScript-like validation
- Offers sensible defaults
- Logs errors for missing required variables
- Can be imported throughout the application

## Security Notes

⚠️ **NEVER** commit `.env` to git - it's in `.gitignore`
⚠️ **ALWAYS** use `.env.example` to document which vars are needed
⚠️ **ROTATE** Supabase keys if accidentally exposed
⚠️ **USE** environment variables for all secrets and configuration

## Migration Guide (if refactoring)

Previously hardcoded values that are now configurable:
- ❌ `ALLOWED_TYPES = ['pdf', 'docx', ...]` → ✅ `VITE_ALLOWED_FILE_TYPES`
- ❌ `MAX_SIZE_MB = 20` → ✅ `VITE_MAX_FILE_SIZE_MB`
- ❌ `setTimeout(..., 300)` → ✅ `VITE_SEARCH_DEBOUNCE_MS`
- ❌ Hard-url-strings → ✅ `VITE_APP_URL`, `VITE_N8N_WEBHOOK_URL`
